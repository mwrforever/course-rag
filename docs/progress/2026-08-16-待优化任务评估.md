## 4. 全局约定 (Locked Conventions)
- AGENTS.md 为纯工程宪法（64096a6 后已更新）：分层依赖（controller→service→mapper）/ Entity 不出 service 边界 / **DTO 根 dto/ 包、VO 根 vo/ 包、转换器集中 convert/ 包（命名 XxxConverter）** / **Service 一律「IXxxService 接口 + impl/ 实现」**（CRUD 型 extends IService，聚合型不继承）/ **异常一律 BizException(ErrorCode.XXX)**（code=HTTP 同值，GlobalExceptionHandler 统一处理，禁局部 @ExceptionHandler）/ 配置类集中 config/、属性类集中 properties/、杂项对象集中 record/、常量集中 constants/ / 层间转换必须 MapStruct 禁手写 / Wrapper 一律 Wrappers 链式禁 new / 禁业务层拼 SQL（含 wrapper.last()）/ 缓存先写 DB 后失效 / 依赖注入 private final + @RequiredArgsConstructor / 禁循环依赖（拆层禁 @Lazy）/ 禁弃用 API / 注释日志全中文 / 查询按需字段 + 分页
- **MapStruct 改造后必须 `mvn.cmd clean` 重编译**（增量编译不重新生成实现类）；MapStruct Impl 只调无参构造器（抽象类构造注入不可行）
- **Git Bash 批处理坑**：grep -rln 输出反斜杠路径 + CRLF 行尾，for 循环前必须 `tr '\\' '/' | tr -d '\r'`
- **MP 测试断言坑**：update 值参数化在 paramNameValuePairs（先 getSqlSet() 触发渲染）；Mockito 禁 stubbing 嵌套、`when()` 不能包 void 方法（doThrow().when()）、泛型 mapper verify 需显式类型
- superpowers 流程固定：核验（源码实锤）→ spec 审批 → plan 审批 → SDD；用户决策必须源码/官方文档实锤；重大交付物需用户审批
- git 纪律：`git add` 只加任务文件禁 `git add -A`；提交 `--no-verify`（pre-commit hook 历史遗留阻塞，见 §2.5）
- 开发库无业务数据可 drop 重建；V6/V7 迁移直接改 + drop 重建，不加增量迁移
- 前端（frontend/ 与 student-frontend/）为空目录未实现；前端对话界面落地前必须与用户沟通
