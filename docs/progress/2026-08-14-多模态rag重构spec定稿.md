### SAA 1.1.2.0 框架坑（源码实锤，勿重复踩）
- **PostgresSaver 自动建表非幂等**: `createTables(true)` 二次启动必炸 `relation already exists`。正确做法: `createTables(false)`，checkpoint DDL 由 `V7__checkpoint_tables.sql` 管理（表名 `GraphThread`/`GraphCheckpoint` 必须与框架 SQL 完全一致）
- **ReactAgent 工具方法必须标 `@Tool`**（org.springframework.ai.tool.annotation.Tool），MethodToolCallbackProvider 强校验
- **ReactAgent.asNode 的节点 id = agent name**: `addNode(id, reactAgent.asNode(...))` 的 id 必须与 `.name(...)` 一致
- 图状态内置策略**仅 2 种**: ReplaceStrategy + AppendStrategy（无 add_messages）；key 名 `messages` 必须 AppendStrategy
- **无 maxIterations 常量**，循环上限用 `ModelCallLimitHook(runLimit=15)`
- Hook 的 AFTER_MODEL **逆序执行**: 注册越晚越先跑
- SM(base) 不落 messages/checkpoint（ModelRequest.systemMessage 独立字段）；SAA 不自动合并多条 SM（自研 CoalescingInterceptor）
- **MessagesModelHook 不可用于瞬时注入**（spec §3.3 源码实锤）: beforeModel 返回的 messages 以 ReplaceAllWith 写回 state 落 checkpoint；瞬时注入必须用 ModelInterceptor；`ModelRequest.context` 来自 `RunnableConfig.metadata`（GraphRunner 单一实例贯穿全图，可作图节点→interceptor 传递通道）
- qwen 思考模型流式输出 thinking/text 两阶段互斥（官方实证）——SseEventTransformer 互斥逻辑正确，勿改

### 数据层约定
