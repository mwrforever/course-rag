## 二、P0 阻塞级（4 项）

### P0-1 权限机制断裂：所有 @PreAuthorize 接口恒 403

- **风险类别**：运行错误（权限体系整体失效，B/C 端管理接口全部不可用）
- **证据**：
  - `backend/src/main/java/com/commerce/rag/auth/SecurityConfig.java:44-63`：过滤链仅 `permitAll()`，未注册任何 JWT 认证过滤器
  - `auth/AuthInterceptor.java:86-88`：JWT 校验后仅 `request.setAttribute(...)`，不写 SecurityContext
  - 全库 `SecurityContextHolder`/`setAuthentication`/`OncePerRequestFilter` **零命中**
  - `@PreAuthorize` 使用面 13 个控制器（AdminUserController:38、AdminCourseController:37、StudentController:46、FeedbackController:27 等）
- **影响**：所有 admin/student/feedback 接口当前对所有人生效地不可用；角色权限体系从未生效
- **修复方向**：AuthInterceptor 或新增 OncePerRequestFilter 校验通过后写入 `SecurityContextHolder`（`UsernamePasswordAuthenticationToken` + `ROLE_` 前缀），保证过滤顺序在方法级鉴权之前
- **详情**：`docs/bugs/2026-08-14-权限机制断裂-所有PreAuthorize接口恒403.md`

## 三、P1 高危（4 项）

### P1-1 登出不吊销令牌

- **证据**：`AuthConfig.java:26-28` 排除 `/api/v1/auth/**` → `AuthController.java:236-261` logout 读拦截器 attribute 恒为 null → 黑名单吊销分支永不执行，仅清 cookie
- **影响**：AT 剩余有效期（默认秒级配置）内 token 仍可调用全部接口；被盗 token 无法撤销
- **修复方向**：logout 从 Authorization header 提取 token 自行吊销，或将该端点移出排除列表
- **详情**：`docs/bugs/2026-08-14-登出不吊销令牌-logout失效.md`

### P1-2 SSE 断线重连无终态事件（含回放竞态）

- **证据**：
  - run 完成后 ring 已移除 → `ChatController.java:226-252` reconnect：replay false → PG 回放 true → subscribe 静默失败（`MemoryStreamBridge.java:69-76` 仅 log.warn）→ 心跳保活（`ChatController.java:245-246`），永无 end 事件
  - 竞态：replay（:226）与 subscribe（:252）窗口内 Worker push 的事件丢失（chat() 端点注释明确"先 subscribe 再入队"，reconnect 未采用同序）
- **影响**：前端永久"生成中"直到 30min emitter 超时；断线重连窗口内事件序号空洞
- **修复方向**：reconnect 中 run 已终态时回放后主动补推 end 事件并 complete；活跃 run 才 subscribe；重排 replay/subscribe 顺序
- **详情**：`docs/bugs/2026-08-14-SSE断线重连无终态事件.md`

### P1-3 取消回滚 checkpoint 类型破坏

- **证据**：`ChatRequestWorker.java:481-493` `deepCopyState` 经 `objectMapper.readValue(json, Map.class)` 使 `List<Message>`→`List<LinkedHashMap>`（ObjectMapper 无 Spring AI Message 多态注册）；`rollbackCheckpoint`（:734-751）写入损坏 checkpoint → 下轮 `LeadAgentGraph.java:150-152` 强转 CCE 或 `persistMessages`（:535）`instanceof Message` 静默跳过
- **置信度说明**：类型丢失本身确定；下游崩溃程度依赖 SAA 1.1.2.0 反序列化细节，本地无 jar 实证，修复时需真实环境验证
- **修复方向**：注册 Message 多态 / 回滚仅恢复 pendingWrites / 取消后删除最新 checkpoint
- **详情**：`docs/bugs/2026-08-14-取消回滚checkpoint类型破坏.md`
